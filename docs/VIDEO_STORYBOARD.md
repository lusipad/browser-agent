## 🎬 基础录制规范与资源

* **配套自动化录制演示**：项目已内置自动录制脚本 `node scripts/gen-demo-video.mjs`，可直接生成 60fps 720p 演示母带视频（保存于 [`docs/videos/browser-agent-v0.6.0-demo.webm`](docs/videos/browser-agent-v0.6.0-demo.webm)）。
* **手动录制工具**：OBS Studio、Windows 自带录屏（`Win + Alt + R`）或 CapCut
* **比例推荐**：16:9（1920×1080 横屏）或 9:16（1080×1920 竖屏聚焦侧边栏）
* **剪辑配乐**：节奏明快的科技卡点 Lo-Fi、Cyberpunk 或 Tech House BGM
