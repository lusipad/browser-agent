# Browser Agent 30秒爆款短视频实操分镜与录制脚本 (Video Storyboard)

> 本脚本专为 **小红书、B 站、微信视频号、抖音** 以及 **YouTube Shorts / X (Twitter)** 制作。
> 按照本分镜录屏 + 剪映一键套字幕，20 分钟内即可产出一条高完播率、高转化的爆款短视频。

---

## 🎬 基础录制规范
* **录制工具**：OBS Studio、Windows 自带录屏（`Win + Alt + R`）或 ScreenToGif
* **浏览器设置**：Chrome 窗口调整为 16:9（如 1920×1080）或 9:16（手机竖屏满屏录侧边栏）
* **剪辑工具**：剪映（移动端/电脑端均可，自带 AI 语音朗读与自动字幕识别）
* **背景音乐建议**：轻快、有科技节奏感的卡点 Lo-Fi 或 Tech House
