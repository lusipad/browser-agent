## 🌟 核心新特性概览

### 1. ⚡ 可复用 SKILL 技能沉淀与自适应回放 (Issue #14)
- **任务一键提炼沉淀**：任务执行完成后，时间线底部自动浮出「保存为技能」卡片，调用模型对执行轨迹进行语义化抽象与参数变量识别（如 `{{keyword}}`、`{{price_limit}}`）。
- **抗改版自然语言意图**：步骤记录为高层意图而非脆弱的绝对 DOM/XPath 选择器，回放时 Agent 结合目标网页实时 DOM 动态自适应定位，页面改版依然稳定。
- **侧边栏 📋 技能抽屉**：侧边栏顶部一键拉出技能面板，浏览全部技能、填写参数表单、一键 `[▶ 运行技能]` 立即触发执行。
- **设置页全能技能编辑器**：提供专门的「技能」管理控制台，支持双栏查看、参数增删与校验规则配置、步骤上下调序 (▲/▼)，以及单个/全量技能 JSON 导入与导出。

### 2. ☁️ 跨设备安全云同步与凭证物理隔离 (Cross-Device Cloud Sync)
- **Chrome 账号多端即时同步**：基于 `chrome.storage.sync`，你在办公室电脑上配置的模型端点与沉淀的技能库，在家中电脑自动同步更新，多端协同无缝衔接。
- **🛡️ 凭证物理隔离（绝不上云）**：
  - API Key 默认**物理隔离**在本地存储（`chrome.storage.local`），写入云端前自动清空脱敏。在公用电脑登录个人账号，也绝无泄露 API Key 的风险。
  - 用户可显式开启「跨设备同步 API Key」（需弹出高风险确认二次授权）。
- **Token 敏感词自动净化**：保存技能时自动过滤变量默认值中的 `sk-...`、`ghp_...` 等敏感 Token，防止误将私钥随技能共享或同步。
- **离线镜像容灾与配额防护**：双层存储架构，所有写操作必然落盘本地，断网或超出 Chrome 100KB 配额时平滑降级，零数据丢失。

### 4. 开发者社区长文 (V2EX / 即刻 / 掘金)

**标题**：开源 Chrome 侧边栏 AI 智能体 Browser Agent v0.5.1：支持工作流沉淀为 SKILL 与零泄露跨设备同步

**正文要点**：
- **引言**：每次让 AI Agent 帮我们在复杂网页中找数据、填表、比价，完成后怎么把这段高价值的工作流变成以后一键可复用的“技能（Macro）”？
- **SKILL 机制解析**：传统自动化工具（Selenium/Puppeteer）靠 CSS/XPath，网页一更新就挂。Browser Agent 采用“语义化意图 + 自适应感知”：保存时 LLM 将操作提炼为自然语言意图（例如“点击标有‘加入购物车’的按钮”），执行时 Agent 结合当下的 DOM 结构智能匹配，抗改版能力极强。
- **跨设备同步如何兼顾安全？**：采用 `chrome.storage.sync` 时，大家最担心的是 API Key 同步到公司电脑或公共电脑导致泄露。我们设计了**分层物理隔离机制**：云端只同步无密钥的配置骨架与技能库，真实 API Key 仅锁死在本机 `chrome.storage.local`，从根源消除安全隐患。
- **体验与开源地址**：代码完全开源，支持 Ollama、DeepSeek、OpenAI 等任意兼容端点。

## 🛠️ 安装与验证方式

1. 下载最新发布的 `browser-agent-0.5.1.zip` 并解压。
2. 打开 Chrome，在地址栏输入 `chrome://extensions/`。
3. 开启右上角的 **「开发者模式」**。
4. 点击 **「加载已解压的扩展程序」**，选择解压出来的目录即可即刻体验！
