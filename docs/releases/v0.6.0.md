# Browser Agent v0.6.0 发布说明与宣发物料指南

> 🚀 **版本主题**：页面视觉框选（指哪打哪）、人操作工具学习（示教录制）、定时调度与人机协同  
> 📅 **发布时间**：2026 年 9 月  
> 🏷️ **Git Tag**：`v0.6.0`  
> 📦 **分发包**：`browser-agent-0.6.0.zip`

---

## 🌟 核心新特性概览

### 1. 🎯 页面视觉框选与指哪打哪 (Visual ROI Selection & Point-and-Shoot)
- **零歧义局部对焦**：点击 Composer 左侧 `🎯` 按钮（或按 `Alt + S` 快捷键），页面即刻进入高亮框选模式，支持拖拽矩形或点击 DOM 元素智能吸附。
- **1:1 像素级高清无感裁剪**：通过 `OffscreenCanvas` 与原生 `captureVisibleTab` 实现无调试警告条的精准局部截图。
- **Token 消耗直降 70%~80%**：仅向多模态模型发送目标局部高保真图像与视口坐标上下文，彻底解决复杂页面、长表格、卡片仪表盘下的定位漂移。
- **缩略图芯片与 Lightbox**：输入框支持挂载选区胶囊徽章，时间线用户消息气泡展示缩略图，点击支持全屏 Lightbox 大图预览。

### 2. 🔴 人操作，工具学习 (Learning from Demonstration / Teach-Me)
- **手把手教 AI 做操作**：点击「🔴 示教录制新技能」，用户直接在真实网页中点击、打字、跳转或上传文件。
- **无感嗅探与隐私脱敏**：后台静默捕获操作序列，自动过滤击键噪声，密码框凭证自动物理脱敏为 `******`。
- **大模型意图自泛化**：结束录制后，大模型自动清洗冗余操作，将物理选择器抽象为抗改版的高层意图，并提取关键变量（如搜索词、上传图片）生成标准 SKILL 技能。

### 3. ⏰ 定时调度与自动化运行 (Scheduled Skills / Cron)
- **周期与每日定时**：支持保存的技能按 15m / 30m / 1h / 6h / 12h / 24h 周期或每日固定时刻（如 09:30）全自动在后台运行。
- **系统通知与状态监控**：基于 `chrome.alarms` 精准唤醒，执行完成后推送 Chrome 桌面系统通知，设置页提供清晰的运行记录与状态看板。

### 4. 🛡️ 人机协同验证码介入 (Human-in-the-Loop Captcha Intervention)
- **安全卡点主动感知**：内置针对极验、滑块拼图、图形验证码、短信二步验证、Cloudflare Turnstile 的自动嗅探器。
- **优雅挂起与一键恢复**：遇到验证阻断时主动挂起执行，在侧边栏弹出橙金呼吸光效协同卡片；用户在网页验证通过后点击「已完成验证，继续执行」，智能体即刻无缝衔接下一步。

### 5. 🚀 长程规划放宽
- `maxIterations` 步数上限扩容至 **500 步**，为极长程复杂多任务与大规模爬取提供充分的执行空间。
