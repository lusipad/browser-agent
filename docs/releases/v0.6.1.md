# Browser Agent v0.6.1 发布说明与更新概述

> 🚀 **版本主题**：技能侧边栏全功能内联编辑、参数支持留空自主分析、设置页路由与精准定位  
> 📅 **发布时间**：2026 年 9 月 18 日  
> 🏷️ **Git Tag**：`v0.6.1`  
> 📦 **分发包**：`browser-agent-0.6.1.zip`

---

## 🌟 核心更新概览

### 1. 📋 侧边栏全要素内联编辑技能 (Inline Skill Editor)
- **运行 / 编辑模式一键切换**：在侧边栏点击技能详情，顶部即可自由切换 `[▶ 运行]` 与 `[✏️ 编辑]`。
- **列表快捷编辑入口**：技能列表中每项悬停展示 `✏️` 按钮，点击一键进入编辑。
- **操作步骤随意调整**：自然语言意图、URL、条件备注全量可调；支持步骤上下移动调序（`▲` / `▼`）、单步删除（`✕`）与追加步骤（`+ 添加步骤`）。
- **参数变量灵活增删**：自由修改参数 Key、中文 Label、类型、预填默认值，支持增删参数。
- **即时保存**：点击「保存修改」立即持久化到 `chrome.storage`，显示成功提示动画。

### 2. 🧠 参数支持留空与智能体自主推导分析
- **默认全为「选填」**：大模型提炼技能时所有参数变量默认设为非必填，界面标签统一显示为绿灰色的 `[选填]`，彻底移除以往阻碍使用的红色 `[必填]` 提示。
- **未填写智能自决策**：留空的参数在执行时转换为 `[自主推导: 变量名]`，由智能体结合当前网页 DOM、URL 及上下文自主分析决策，解决用户“参数没法填”的困扰。

### 3. 🎯 生成后即时唤起与深度设置联动
- **生成即唤起**：无论从任务对话提炼技能还是示教录制生成技能，完成后自动唤起侧边栏该技能的编辑视图，方便第一时间校验和微调。
- **设置页精准路由**：修复“在设置中管理”时错误停留在模型配置页的问题，支持通过 URL 参数精准打开技能面板并自动高亮选中目标技能。

## 📢 GitHub Release Notes

```markdown
## What's Changed in v0.6.1

### 📋 Sidepanel Inline Skill Editor
- Easily switch between "Run" and "Edit" modes inside the sidepanel SkillDrawer.
- Direct `✏️` shortcut button on each skill in the list.
- Full inline editing of skill name, emoji icon, description, steps (reorder, add, delete, update intent/URL), variables, and cron schedule.
- Instant feedback and persistence to storage.

### 🧠 Auto-Inference for Unspecified Parameters
- Generated skill parameters are now non-required (`required: false`) by default.
- Parameters left blank are autonomously deduced by the agent based on current page context and DOM structure.
- Removed confusing red "Required" badge on auto-generated workflows.

### 🎯 Direct Deep-Link Routing to Skills Settings
- Fixed "Manage in Settings" navigation to land directly on the Skills panel instead of Providers.
- Automatically selects and scrolls to the target skill when navigated with `?tab=skills&skillId=...`.
- Real-time synchronization with options page via `onSkillsChange`.

**Full Changelog**: https://github.com/lusipad/browser-agent/compare/v0.6.0...v0.6.1
```
