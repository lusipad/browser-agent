## 🌟 核心更新概览

### 1. ⚡ System 1 (Jev / Laya) 快慢双核混合架构 (Dual-Process Hybrid Architecture)
- **双核分工（快与慢协同）**：
  - **System 1 (直觉反射层 / Fast-Path)**：集成 TypeSafe Jev 云端模型及 Laya 本地决策模型，响应时间缩减至 **200ms – 800ms**，在毫秒级内完成页面确定性动作（点击按钮、超链接跳转、输入框输入、页面滚动）的预测与 CDP 物理执行。
  - **System 2 (深层推理层 / Slow-Path)**：大模型（GPT / DeepSeek）专注负责长程规划、意图拆解、复杂多模态理解与文章精读归纳。
- **性能飞跃与 Token 暴降**：
  - 常规页面翻页、导航与单选操作无需每次向大语言模型上传全屏多模态截图，Token 消耗压降 **80% 以上**，单步延迟提速 **5–10 倍**。
- **置信度门限与自动回退 (Fallback)**：
  - 严格校验 Jev 决策置信度（默认门限 0.6–0.7），置信度不足或遇复杂开放式任务时平滑交由 System 2 接管，确保既快又稳。

### 2. 🎨 原生侧边栏时间线实时状态卡片 (System 1 Execution Cards)
- **毫秒级绿标反馈**：原生侧边栏时间线实时渲染带有专属高亮图标的 `⚡ System 1 (Jev)` 执行状态卡，动态展示动作类型、目标元素编号、预测置信度与端到端耗时毫秒数。
- **真机流式融合**：双核协同过程在原生 UI 体系中顺畅呈现，直观反映智能体的实时物理操作轨迹。

### 3. ⚙️ 高级设置面板集成与密钥物理隔离 (Local Secret Isolation)
- **System 1 独立配置看板**：设置页「高级设置」面板新增独立 System 1 配置分区，支持一键启闭、服务商切换（TypeSafe / Laya 本地 / 自定义端点）、BaseUrl、API Key 与置信度阈值调优。
- **密钥本地隔离防护**：API Key 通过 `local_api_keys` 分层隔离存储，绝不上云同步，确保隐私与安全物理合规。
