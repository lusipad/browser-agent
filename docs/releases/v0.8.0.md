# Browser Agent v0.8.0 发布说明与更新概述

> 🚀 **版本主题**：全链路活体执行 HUD 与点击涟漪、深度思考流折叠面板、SPA 动态稳定结算、示教自愈重放、auto_cards 无选择器提取与 WebBridge MCP 守护进程  
> 📅 **发布时间**：2026 年 10 月 22 日  
> 🏷️ **Git Tag**：`v0.8.0`  
> 📦 **分发包**：`browser-agent-0.8.0.zip`

---

## 🌟 核心更新概览

### 🌟 新一代前沿旗舰模型全面支持 (Frontier AI Lineup)
- **全面接入 2026 前沿旗舰与深度思考模型**：
  - OpenAI: **GPT-6 Astra**（旗舰级长程推理与物理级操控）、**GPT-6.1 Sol**（高性能生产主力）、GPT-6 Luna。
  - Anthropic: **Claude Sonnet 5.5**（Adaptive Thinking 深度思考）、**Claude Opus 5.5**、Claude Fable 5.1。
  - DeepSeek: **DeepSeek V4.1 Flash**、**DeepSeek V4 Flash**（原生视觉与流式推理双核）。
- 完整同步百万级上下文（1M Context Window）、自适应 Thinking 过程解析与最新分级计费元数据。

### 1. 🧠 深度思考流式折叠面板 & SPA 动态稳定协议 (Phase 6)
- **实时思考流折叠面板 (Thinking Accordion)**：
  - 针对 GPT-6 系列（GPT-6 Astra / GPT-6.1 Sol）、Claude 5.5 系列（Claude Sonnet 5.5 / Opus 5.5）、DeepSeek V4.1 系列等具备前沿深度思考与自适应推理的模型，提供侧边栏实时思考流展示。
  - 折叠设计避免长链条思维内容淹没核心操作，点击即可展开审阅详细心智过程。
- **SPA 页面动态稳定协议 (`page_settle`)**：
  - 深度适配现代 React、Vue、Angular 单页应用。
  - 基于 MutationObserver 结合网络微任务静默窗口，智能侦测动态加载与渲染结算，彻底杜绝元素未渲染即点击导致的偶发性失败。

### 2. 📊 启发式卡片流抽取 & 人机协同焦点增强 & `/extract` (Phase 5)
- **无选择器卡片流抽取 (`auto_cards`)**：
  - 智能聚合电商商品流、新闻列表、社交动态等卡片结构，无需用户或大模型手工调试复杂 CSS Selector。
- **人机协同焦点升顶与全屏 HUD**：
  - 遇到验证码、二次验证或登录保护时，触发 `request_human_intervention` 自动将目标 Tab 升顶至前台，在页面浮现醒目 Human HUD 状态条。
  - 用户解决后一键平滑接管，长程会话不中断。
- **快捷指令**：新增 `/extract` 斜杠指令，支持在对话框即时触发多维度数据结构化抽取。

### 3. 🎯 活体执行 HUD 与点击涟漪 & 本地 WebBridge MCP 守护 (Phase 4)
- **物理操作可视化感知**：
  - 物理点击即时伴随动态激光波纹（Pointer Ripple），当前步骤意图实时显现在页面浮层 HUD 上，提供极佳的掌控感。
- **本地 WebBridge 守护进程 (`webbridge-daemon`)**：
  - 内置 WebSocket 守候服务与标准 MCP (Model Context Protocol) 服务端，支持外部 IDE、Cursor、Claude Desktop 或终端脚本直接操控浏览器。
- **WebSkillCreator 元流转协议**：
  - 自动将用户日常示教操作提炼为标准化、结构化的参数化技能包。

### 4. 🎬 示教技能多层定位器与分级自愈重放 (Phase 3)
- **独立录制标签页组 (Recording Tab Group)**：
  - 示教录制自动分配独立 Chrome 标签组隔离进行，避免与日常工作标签混淆。
- **Level 0~2 分层重放自愈机制**：
  - 自动抽取包含 ID、CSS 选择器、XPath、文本内容与 ARIA Role 的复合定位器。
  - 支持 Level 0 极速直放、Level 1 启发式自动修复与 Level 2 LLM 语义重定位三重保险。

### 5. 🌐 有状态网络请求检查器与快捷指令集 (Phase 2)
- **网络嗅探器 (Network Inspector)**：
  - 深度集成 CDP 网络域，捕获并分析目标站点的 HTTP 状态、请求载荷与响应耗时。
- **快捷指令集**：支持 `/compact`（就地压缩长上下文）、`/clean`、`/help` 等斜杠操作。

### 6. 🛡️ 智能多屏连续滚动与 DOM 引用自愈 (Phase 1)
- **智能滚动行抽取 (`smart_scroll_read`)**：
  - 自适应探测滚动容器，支持多屏连续捕获并智能进行行级去重，完美适配无限信息流。
- **DOM Ref 动态自愈 (Ref Healing)**：
  - 节点变动刷新后自动匹配最优候选，保持会话上下文连贯。
- **原生 CDP 对话框接管**：
  - 拦截并安全响应 Alert / Confirm / Prompt 弹窗。

### 7. ⚡ System 1 (TypeSafe Jev 1.14+) 视觉坐标与多模态直觉执行
- **视觉坐标系统**：接入 Danger Zone 图像通道，解析视觉 Box 像素坐标并映射为物理鼠标精准点击。
- **选项页专属设置**：支持视觉决策（Vision Enabled）开关控制与中英双语国际化。
