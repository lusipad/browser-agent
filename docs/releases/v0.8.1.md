## 🌟 核心更新概览

### 1. 🔁 大模型空响应与瞬时流异常指数退避重试 (Fixes #16)
- **智能退避重试机制**：
  - 针对特定模型（如 `deepseek-ai/DeepSeek-V4.1-Flash`）或第三方代理偶发的瞬时空响应（返回 HTTP 200 但无文本且无工具调用）以及流传输中途网络抖动（5xx / 429 / TypeError），自动执行指数退避重试（默认最多重试 2 次，可在高级设置中调整）。
  - 重试期间自动重置流式累积与助手时间线卡片状态，并向用户展示清晰友好的重试提示（`模型「...」返回空响应，正在重试（第 1/2 次）...`）。
  - 彻底杜绝任务因单次瞬时网络或服务端偶发异常而崩溃中断，且重试阶段绝不往对话历史中写入 `(empty)` 污染消息。
- **全流程覆盖**：
  - 主智能体循环（Navigator）、任务拆解规划器（Planner）以及页面状态自检校验器（Validator）全面接入重试保护。

### 2. 🧹 网页原生交互体验纯净化 (Zero-Distraction Web Experience)
- **彻底移除网页划选浮动快捷胶囊**：
  - 不再自动向页面注入划词浮层，避免与用户系统中已有沉浸式翻译、划词工具产生 UI 冲突或遮挡网页原生选中交互，保持纯粹的侧边栏与自动化驱动定位。

### 3. 🛡️ 工具分片解析防御
- 在流式 SSE 协议解析中过滤空白函数名，防止网关或反代偶发下发畸形工具调用分片。
