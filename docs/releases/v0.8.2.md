## 🌟 核心更新概览

### 1. ⚡ 正式集成 Google Gemini Decisions API (`gemini-decision-1`)
- **全新快决策（System 1）提供商支持**：
  - 针对 Google 近期推出的专用决策模型与 REST Decisions API (`https://generativelanguage.googleapis.com/v1beta/decisions`)，提供原生协议适配与全套调用链支持。
  - 用户可在设置中心「⚡ 极速决策 (System 1)」中一键选择 `Google Gemini (gemini-decision-1 极速决策 API)`，输入 Gemini API Key 即可享受低延迟动作决策。

### 2. 👁️ 多模态视口感知与结构化候选映射
- **多模态 `inline_data` 图像传输**：
  - 结合页面当前视口截图与文本状态，以 Gemini 规范的 `inline_data` 传输视觉证据，兼顾布局直觉与文本定位。
- **结构化 Choice 问题路由**：
  - 将浏览器目标意图自动转化为 `action` 与 `target` 两个结构化决策问题，将页面关键 DOM 元素候选 (`[ref_1]` ~ `[ref_N]`) 自动映射为 `criteria` 选项集，实现模型对浏览器操作意图与点击目标的精确评估。

### 3. 📊 置信度与概率分布校准
- 解析 Google Decisions API 的 `answers` 规范响应，读取 `probabilities` 分布及 `high` / `medium` / `low` 置信度评级，校准后参与 System 1 放行阈值控制，低于阈值时平滑回退至 System 2 长程慢思考。

### 4. 🎛️ 侧边栏状态与设置联动
- 侧边栏顶部 ⚡ 徽章与详情弹窗全面适配 `gemini-decision-1`，实时展现快决策耗时与置信度。
